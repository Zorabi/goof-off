# Goof Off

一款为「摸鱼」而生的隐身阅读器：TXT / EPUB / PDF 阅读 + 内嵌浏览器，随时透明、随时隐藏、随时消失。

## 这是什么

Goof Off 把本地阅读器（TXT / EPUB / PDF）和一个内嵌网页浏览器装进一个不起眼的小窗里，再配上一整套「隐身」能力：

- **透明** —— 窗口背景完全隐去，文字直接浮在桌面上，淡化强度随意调；
- **闪避** —— 全局老板键一键隐藏 / 恢复，「熔断」键瞬间退出；鼠标一离开窗口，正文自动淡出、点击穿透到下层窗口；
- **无痕** —— 可以不占任务栏 / Dock，只留一个托盘图标；历史记录可关闭、可清空。

支持 macOS（Apple Silicon）与 Windows 11 x64。所有数据（阅读进度、偏好、历史）仅保存在本地。

## 功能特性

**阅读**

- TXT：自动识别章节、全文搜索、编码自动检测（UTF-8 / GBK / GB2312 / Big5，可手动切换）、自动翻页；大文件优化（> 256 KB 后台线程解析，> 1 MB 虚拟滚动）
- EPUB：目录、搜索、滚动 / 翻页双模式、字体字号行距排版（不支持加密 EPUB）
- PDF：书签目录、适宽 / 适页 / 自定义缩放（25%–400%）、页码跳转、Range 流式加载
- 每个文件的进度与排版单独记忆，重开续读；启动时自动恢复上次阅读（可关闭）

**内嵌浏览器**

- 地址栏智能识别：网址直接打开，其余关键词走 Bing 搜索；输入时给出历史 / 收藏建议
- 「常用站点」卡片：预置微信读书、B站、小红书、抖音；可增删改、拖动排序，浏览中一键收藏当前页
- UA 伪装：默认 iPhone（移动版页面更小更清爽），可选 macOS / Windows / iPad，支持按站点覆盖
- 网页素览（去背景）、隐藏媒体（图片 / 视频）、隐藏滚动条、页面缩放、滚轮速度调节
- 网页 / 文件历史（各保留最近 100 条，可关闭、可清空）

**隐身**

- 背景隐去 + 界面淡化（强度 0–95%）：窗口只剩内容浮在桌面上
- 全局老板键：隐藏 / 恢复（默认 `Ctrl+\` / `⌘+\`），熔断即退（默认 `Shift+Ctrl+\` / `⇧⌘+\`），键位可自定义
- 主体自动隐藏：鼠标离开窗口正文即淡出，macOS / Windows 11 上同时开启鼠标穿透
- 工具栏自动隐藏，靠近窗口上下边缘 44 px 热区唤出
- 任务栏 / Dock 图标可隐藏，仅留托盘图标；窗口可置顶
- 精简模式：280×500 迷你小窗（TXT / EPUB）

## 安装

### 方式一：下载安装包（推荐）

前往 [Releases](https://github.com/triWater-Chen/goof-off/releases) 页面，下载对应平台的最新版本：

- **Windows 11 x64**：`Goof-Off-x.x.x-Setup.exe`（安装版）或 `Goof-Off-x.x.x-Portable.exe`（便携版，免安装）
- **macOS（Apple Silicon）**：`Goof-Off-x.x.x.dmg` 或 `Goof-Off-x.x.x.zip`

> 安装包未做代码签名：Windows 首次运行如弹出 SmartScreen 警告，请点「更多信息 → 仍要运行」；macOS 如提示「无法验证开发者」，请右键 App → 「打开」。

### 方式二：从源码构建

要求 Node.js ≥ 22.12.0、npm ≥ 10.9.3。

```bash
git clone https://github.com/triWater-Chen/goof-off.git
cd goof-off
npm install     # 自动下载 Electron 二进制并重建原生依赖
npm run dev     # 开发模式启动（HMR）
```

打包分发版本：

```bash
npm run build:win      # Windows：NSIS 安装包 + 便携版（x64），输出到 dist/
npm run build:mac      # macOS：DMG + ZIP
npm run build:unpack   # 只产出未打包目录，便于本地验证
```

> - Electron 二进制下载缓慢时，可先设置镜像再重新 `npm install`：`ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`。
> - 仓库中虽有 `build:linux` 脚本，但平台策略（`src/shared/platformPolicy.js`）未适配 Linux，不保证可用。

## 使用教程

### 快速上手

1. 启动后进入主页。
2. **读书**：把一个 `.txt` / `.epub` / `.pdf` 文件拖进窗口（一次一个），或点主页的「点此打开」选择文件；也可用快捷键 `Ctrl/⌘+O`（TXT）、`Ctrl/⌘+Shift+O`（EPUB）、`Ctrl/⌘+Alt+O`（PDF）。
3. **上网**：点「常用站点」卡片，或在顶部地址栏输入网址 / 关键词后回车。
4. 退出后下次启动会自动回到上次的页面或阅读位置（偏好设置 → 系统 → 「启动时恢复上次阅读」可关闭）。

### 老板键：一键隐藏 / 熔断

| 动作 | Windows | macOS | 行为 |
| --- | --- | --- | --- |
| 隐藏 / 恢复 | `Ctrl + \` | `⌘ + \` | 可见时隐藏；已隐藏时恢复；未开窗时拉起主窗口 |
| 熔断 | `Shift + Ctrl + \` | `⇧ + ⌘ + \` | 立即退出应用 |

- 这是系统级全局快捷键，窗口隐藏后依然有效。
- 改键：偏好设置 → 快捷键 → 「老板键」，点击键位按钮后按下新组合（`Esc` 取消；键位被系统占用时会提示并保留原键位）。
- 找回窗口：再按一次隐藏键，或点系统托盘图标 → 「恢复显示」。

### 隐身模式实战

打开一本书或一个网页后，按下面的顺序把隐蔽性逐级拉满：

1. **背景隐去**：底部工具栏 → 「视觉控制」→ 打开「背景隐去」，窗口背景消失，内容直接浮在桌面上；再打开「界面淡化」并拖动「界面淡化强度」滑杆（0–95%），让内容若隐若现。
   - 嫌两个开关麻烦：偏好设置 → 视觉 → 勾选「隐身阅读」，合并成一个总开关。
2. **工具栏自动隐藏**：右上「更多」菜单 → 勾选「工具栏自动隐藏」（需先开启背景隐去）。顶栏 / 底栏自动缩起，鼠标移到窗口上下边缘约 44 px 的热区即唤出。
3. **主体自动隐藏**：同一菜单勾选「主体自动隐藏」。鼠标一离开窗口，正文自动淡出到不可见；在 macOS 和 Windows 11 上还会同时开启**鼠标穿透**——此时点击会直接落到下层窗口，仿佛这个窗口不存在。鼠标移回热区或按键即恢复显示。
4. **隐藏任务栏 / Dock 图标**：偏好设置 → 系统 → 取消勾选「在任务栏 / Dock 中显示」。此后找回窗口只剩两条路：老板键，或托盘图标。
5. **常驻小窗**（可选）：「更多」菜单 → 「窗口置顶」把窗口钉在最前；读 TXT / EPUB 时再点「精简模式」缩成 280×500 小窗（小窗内菜单 → 「退出精简态」还原）。

浏览网页时还有两个净化开关（「视觉控制」面板内；开启透明后底栏也会出现快捷图标）：

- 「网页素览」：去掉网页背景色 / 背景图，与透明模式搭配最佳；
- 「隐藏媒体」：隐藏图片和视频，只留文字。

### 阅读操作

打开文件后，底部工具栏提供「目录 / 搜索 / 排版 / 自动翻页」等按钮（随格式略有差异）；点击底部页码 / 百分比可直接输入跳转。

| 按键 | 作用 |
| --- | --- |
| `Space` / `Shift+Space` | 下一页 / 上一页（可在偏好设置修改，不允许 Ctrl/⌘ 组合） |
| `PageDown` / `PageUp`、方向键 | 翻页 / 滚动（EPUB 中 `←` `→` 为切换章节） |
| `Ctrl/⌘ + F` | 全文搜索（TXT / EPUB） |
| `T` / `A` | TXT：开关目录 / 自动翻页 |
| `Home` / `End` | TXT：跳到开头 / 结尾 |
| `Ctrl/⌘ + =` / `-` / `0` | PDF：放大 / 缩小 / 重置缩放 |
| `Esc` | 逐层收起面板 / 菜单 / 输入框 |

- **TXT**：自动识别章节生成目录树，支持删除指定章节；乱码时在「排版」面板手动切换编码，立即生效。
- **EPUB**：「排版」面板可切换滚动 / 翻页两种阅读模式；不支持加密（DRM）EPUB。
- **PDF**：「PDF 适配」面板选择适宽 / 适页 / 自定义比例（25%–400%）；PDF 不应用自定义背景与文字颜色。
- **自动翻页**：面板中开启并设置间隔（5–180 秒）。

### 网页浏览细节

- 地址栏规则：`http(s)://` 开头直接打开；形如 `example.com` 的输入自动补 `https://`；其余内容用 Bing 搜索。
- 网页默认以 iPhone UA 打开。站点显示异常时：偏好设置 → 模式 → 网页，切换「用户代理」，或仅对当前站点勾选「站点覆盖」单独设置；「兼容模式」会强制使用 iPhone UA。
- 收藏：浏览时点地址栏右侧的星标，当前页面即成为主页的站点卡片；卡片右键可「编辑 / 删除」，拖动可排序。

### 历史

主页 → 「历史」卡片，分「网页历史 / 文件历史」两栏，按今天 / 昨天 / 本周 / 更早分组。单条悬停可删除；「清空」需二次确认。点击已被移动 / 删除的文件记录时，会询问是否顺手删掉这条历史。不想留记录：偏好设置 → 系统 → 关闭「记录网页历史」/「记录文件历史」。

### 偏好设置

「更多」菜单 → 「偏好设置」，或快捷键 `Ctrl/⌘ + ,`。四个标签页：

| 标签 | 内容 |
| --- | --- |
| 视觉 | 应用主题（自动 / 浅色 / 深色）、隐身阅读开关与淡化强度、TXT / EPUB 阅读背景（文字颜色、渐变背景） |
| 模式 | 网页（UA / 兼容模式 / 滚动条 / 缩放，全局与按站点）、TXT / EPUB / PDF 默认排版与自动翻页参数 |
| 快捷键 | 老板键、自定义翻页键、内置快捷键速查 |
| 系统 | 启动恢复、历史开关与清空、任务栏 / Dock 图标、诊断日志、缓存清理、应用初始化、配置导出 / 导入 |

## 常见问题

- **窗口不见了怎么找回？** 按老板键（默认 `Ctrl+\` / `⌘+\`），或点系统托盘的 Goof Off 图标 → 「恢复显示」。
- **某个网站打不开 / 排版错乱？** 偏好设置 → 模式 → 网页：换一个「用户代理」，或对该站点开「站点覆盖」；仍不行再试「兼容模式」。
- **TXT 打开是乱码？** 阅读界面 → 「排版」→ 「编码」手动切换（UTF-8 / GBK / GB2312 / Big5）。

## 项目结构

```
src/
├── main/       # 主进程：窗口、内嵌浏览器、老板键与托盘、透明度、各文件格式服务等 ~30 个模块
│   └── txtWorker.js    # 独立构建入口：大 TXT 在 worker_threads 中解析
├── preload/    # 四个 preload：主窗口、偏好设置、弹层、网页原生对话框替换
├── renderer/   # 三个独立 Vue 应用：主界面、偏好设置窗口、弹层窗口
└── shared/     # 主 / preload / 渲染三端共享的纯模块（平台策略、弹层协议、布局模型等）
```

- 内嵌浏览器基于 `WebContentsView`（而非 `<webview>` 标签），UA、CSS 注入、滚轮脚本均由主进程统一管理。
- PDF 经自定义特权协议 `goof-off-pdf://` 以 Range 流式供给 pdf.js。
- 全部 IPC 通道集中注册于 `src/main/ipcHandlers.js`（命名 `domain:action`）；持久化使用 electron-store，schema 见 `src/main/store.js`。
- 平台差异统一收敛在 `src/shared/platformPolicy.js`，业务代码不直接判断 `process.platform`。

## 开发

```bash
npm run dev      # 开发模式（HMR）
npm run build    # 构建 main / preload / renderer 到 out/
npm start        # 预览构建产物
npm run lint     # ESLint（--max-warnings=0，出现警告即失败）
npm run format   # Prettier 格式化
```

- 环境变量 `GOOF_OFF_STEALTH_SPIKE=1` 启用实验性隐身探测路径（默认关闭，仅用于开发调试）。
- 结构化诊断日志（JSONL）写入用户数据目录下的 `logs/`，可在偏好设置 → 系统中关闭。
